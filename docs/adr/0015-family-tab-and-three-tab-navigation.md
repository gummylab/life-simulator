# สามแท็บและหน้าครอบครัว: ให้พ่อแม่ คู่ครอง และบุตรมีที่อยู่ของตัวเอง

ADR 0013 ตัดแท็บ "บันทึก" ออกเหลือสองแท็บ (กิจกรรม / อื่นๆ) เพื่อให้ฟีดรายปีอยู่ติดการ์ดกิจกรรม การตัดนั้นถูกสำหรับ "บันทึก" แต่ทิ้งปัญหาหนึ่งไว้: **หน้าครอบครัวไม่มีอยู่เลย** ทั้งที่ `Character.family` เก็บพ่อ แม่ คู่ครอง และบุตรครบทุกคนพร้อมชื่อและปีเกิดมาตั้งแต่ Phase 2 และเป็นข้อมูลที่ผู้เล่นกดสร้างเองทุกปี (เดท แต่งงาน มีลูก หย่า) ผู้เล่นจึงกด "มีลูก" แล้วเห็นแค่บรรทัดในบันทึกชีวิต ไม่มีที่ให้ดูว่าลูกชื่ออะไร อายุเท่าไร มีพี่น้องกี่คน และถ้าไม่เปิดหน้าอื่น ๆ ก็ไม่มีทางรู้ด้วยซ้ำว่าตัวละครมีคู่แล้ว

## กลไก

**สามแท็บ**: `TABS` ใน `src/ui/App.ts` เป็น `life` (ชีวิต), `family` (ครอบครัว), `more` (อื่นๆ) แท็บกิจกรรมเดิมถูกเปลี่ยนชื่อเป็น "ชีวิต" เพราะมันไม่ใช่แค่เม뉴กิจกรรมอีกต่อไป แต่เป็นทั้งแถบสถานะ ฟีดรายปี เม뉴 และแผงการงาน กริดของ `.tabs` เป็น `repeat(3, 1fr)` ซึ่งตรงกับจำนวนแท็บจริง (เดิมเป็น 3 คอลัมน์ทั้งที่มี 2 ปุ่ม ทำให้แถบล่างชิดซ้าย)

**แถบสถานะและปุ่มจบปีอยู่เฉพาะแท็บชีวิต**: `gameScreen` สร้าง `HudView` เมื่อ `tab === "life" && character.alive` เท่านั้น และส่ง `showAdvance = tab === "life"` ให้ `dock` แท็บครอบครัวและแท็บอื่นๆ จึงอ่านเต็มจอโดยไม่ถูกแถบสถานะแย่งที่

**`FamilyView` (ใหม่)**: reads `GameState` อย่างเดียว ไม่มีกติกา
- แผง "คนในครอบครัว": พ่อ แม่ (จาก `family.parents` แยกด้วย `gender`) คู่ครอง (ป้ายเปลี่ยนเป็น "คู่สมรส" เมื่อ `married`) และบุตรทุกคนพร้อมลำดับ
- แต่ละคนแสดงชื่อ-นามสกุล อายุ (`state.year - birthYear`) หรือข้อความ "เสียชีวิตเมื่ออายุ N ปี" ถ้ามี `deathYear`
- สถานะว่างมีคำใบ้ที่บอกกติกา: "ยังไม่มีคู่รัก — ไปเดทได้ตั้งแต่อายุ 16 ปี" และ "ยังไม่มีบุตร — ต้องแต่งงานก่อนจึงจะมีลูกได้"
- แผง "ตระกูล": รุ่นที่ สมาชิกที่บันทึกไว้ ชื่อตระกูลตั้งต้น และปุ่มเปิดบันทึกตระกูล (`open-chronicle`) เมื่อมีบรรทัดแล้ว

**ทางเข้าบันทึกตระกูล**: เดิมเข้าจากแถวในหน้าอื่นๆ เท่านั้น ตอนนี้มีปุ่มในแผงตระกูลของแท็บครอบครัวด้วย โดยยังคงแถวเดิมในหน้าอื่นๆ ไว้ (ผู้เล่นหาจากที่ไหนก็เจอ)

## Considered Options

- **A. เพิ่มแท็บที่สาม (เลือก)**: ครอบครัวได้หน้าที่มีน้ำหนักเท่ากับลูปกิจกรรม และจำนวนแท็บยังอยู่ในช่วงที่นิ้วโป้งเอื้อมถึงทั้งสามปุ่ม
- **B. คงสองแท็บ แล้วเปิดหน้าครอบครัวจากแถบสถานะ**: ประหยัดพื้นที่ล่าง แต่ซ่อนฟีเจอร์ไว้หลังการกดที่ไม่มีอะไรบอกว่ากดได้ และผู้เล่นที่ตัวละครตายแล้วจะไม่มีแถบสถานะให้กดเลย
- **C. หน้าเดียว + bottom sheet**: ต้องมี state sheet เพิ่มและ stacking ของ sheet กับ dock มากกว่าที่เกมขนาดนี้ต้องการ
- **D. สี่แท็บ (เพิ่ม "บันทึก" กลับมา)**: ขัดมติ ADR 0013 ที่เพิ่งตั้งไว้ว่าบันทึกไม่ควรเป็นแท็บ เพราะปุ่มที่เปิดได้เฉพาะตอนสลับแท็บไม่ตอบลูป "เห็นผลทันที"

## Consequences

- คำสั่งเปลี่ยนจาก `tab:act` เป็น `tab:life` และเพิ่ม `tab:family` ทุกที่ที่อ้างถึงจึงต้องแก้ (`App`, `App.test.ts`, `Playtest.test.ts`)
- `View` ไม่เพิ่มสถานะสำหรับครอบครัว เพราะเป็นแท็บไม่ใช่หน้าย่อย การกด "กลับ" จากหน้าย่อยจึงกลับเข้าสู่แท็บครอบครัวได้ตามปกติ
- `LifeSummaryView` เพิ่มบรรทัด "บุตร" ในรายการข้อเท็จจริง เพื่อให้ชีวประวัติบอกครอบครัวด้วย ไม่ใช่บอกแค่การศึกษาและอาชีพ
- แถบนำทางล่างต้องมีสามปุ่มเท่ากันจริงตามที่ ADR 0013 ตั้งใจไว้
