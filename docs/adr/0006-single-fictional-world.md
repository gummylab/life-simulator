# โลกสมมติเดียวของเราเองและชื่อทับศัพท์อักษรไทย

ระบบเลือกประเทศ (ไทย/อเมริกา) ถูกถอดออกทั้งหมด ทั้งหน้าตั้งค่าก่อนเกิด, `CountryPack` และ test ที่เกี่ยวข้อง เพราะเจ้าของเกมเลือกสร้างโลกของเราเองขึ้นมาใหม่แทนการอิงประเทศจริง ชื่อคน ชื่อตระกูล ชื่อโรงเรียน ชื่อมหาวิทยาลัย และชื่อเมือง เป็นชื่ออังกฤษที่เขียนเป็นอักษรไทยทับศัพท์ เช่น เอมม่า มิลเลอร์ และกรีนฟิลด์ ไฮ ป้ายระดับการศึกษายังเป็นภาษาไทยคือประถม มัธยม และมหาวิทยาลัย

**Considered Options:** คงระบบ 2 ประเทศไว้ ถูกตัดออกเพราะเนื้อหาจะเพิ่มเป็นเท่าตัว และเมื่อชื่อทุกอย่างเป็นทับศัพท์อังกฤษ จุดต่างระหว่างประเทศก็เหลือเพียงสกุลเงิน ส่วนอีกทางเลือกคือใช้ชื่ออังกฤษอักษรโรมันเต็มตัว ถูกตัดออกเพราะเจ้าของเกมอยากเห็นชื่อเป็นอักษรไทยตามตัวอย่างที่พิมพ์มา

**Consequences:** เนื้อหาทั้งหมดอยู่ในไฟล์ `src/content/world.ts` ชุดเดียว เหตุการณ์ดึงชื่อสถาบันและสถานที่ผ่าน token จากไฟล์นี้ ถ้าอนาคตอยากมีหลายโลก ให้ดู ADR 0005 ที่เล่าโครงประเทศที่ถูกถอดไว้
