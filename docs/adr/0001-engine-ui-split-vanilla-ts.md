# แยกแกนเกมออกจาก UI และไม่ใช้ UI framework

แกนเกมต้องรันในเบราว์เซอร์ได้โดยไม่พึ่ง DOM เพื่อให้ test ได้ทั้งหมดด้วย `bun test` และเพื่อให้เปลี่ยนหน้าจอภายหลังได้โดยไม่แตะ logic เกม เราจึงวางโค้ดเป็นสามชั้นคือ `core` ที่เป็น logic ล้วน, `content` ที่เป็นข้อมูลภาษาไทย และ `ui` ที่ render ใหม่ทั้งหมดจาก state ทุกครั้งที่มีการกดปุ่ม

**Considered Options:** ใช้ React หรือ Vue เพื่อจัดการหน้าจออัตโนมัติ ถูกตัดออกเพราะเกมเป็นแค่ข้อความกับปุ่ม ต้นทุนของ framework ไม่คุ้ม และทำให้ `core` มี dependency ที่ test ต้องจำลอง DOM ตาม

**Consequences:** ทุก view ต้องไม่ดัดแปลง DOM แบบย่อยๆ และห้าม import อะไรจาก `core` ฝั่งกลับ ถ้าอนาคต UI ซับซ้อนขึ้นจริง ค่อยเพิ่ม framework ทับชั้น `ui` ได้โดยไม่ต้องรื้อ `core`
