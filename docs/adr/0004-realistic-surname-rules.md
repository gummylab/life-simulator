# นามสกุลตามธรรมเนียมจริงแทนชื่อตระกูลคงที่ทุกรุ่น

ตอนออกแบบระบบตระกูล เดิมวางไว้ว่าชื่อตระกูลที่ตั้งตอนแรกจะติดกับทุกรุ่นเพื่อให้ HUD และบันทึกตระกูลดูต่อกัน แต่เจ้าของเกมเลือกยึดความจริงตามชีวิตจริงแทน คือลูกได้นามสกุลพ่อ และผู้หญิงแต่งงานแล้วเปลี่ยนเป็นนามสกุลสามี สายเลือดของตระกูลจึงโยงกันด้วยตัวบุคคลใน family tree ไม่ใช่นามสกุล ดังนั้นรุ่นไหนนามสกุลเปลี่ยนก็ไม่กระทบการสืบทอด

**Consequences:** ห้ามมีโค้ดส่วนไหนสมมติว่าทุกคนในตระกูลใช้นามสกุลเดียวกัน HUD และหน้าชีวประวัติแสดงชื่อปัจจุบันของตัวละคร ส่วนบันทึกตระกูลแสดงชื่อของแต่ละคน ณ ปีที่บันทึกไว้ ถ้าอนาคตมีคนเข้าใจว่าชื่อตระกูลที่เปลี่ยนกลางเกมเป็นบั๊ก ให้ชี้มาที่ ADR ฉบับนี้
