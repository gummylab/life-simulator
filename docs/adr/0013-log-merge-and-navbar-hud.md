# รวมบันทึกเข้าแท็บกิจกรรม: ฟีดรายปี, แถบสถานะ, สองแท็บ

Phase 5 แยก "อ่านสถานะ → เลือกทำ → จบปี → เห็นผล" ไว้สามจุดคือ HUD, การ์ดข่าวท้ายปี, แท็บบันทึก ผู้เล่นจึงต้องกระโดดไปแท็บอื่นเพื่อดูผลของปี ทั้งที่ผลมันควรอยู่ชิดกับการ์ดกิจกรรมที่เพิ่งกด ปัญหาจริงจาก Playtest คือการ์ดข่าวว่างเปล่าหลัง refresh กลางปี เพราะ `news` เป็นลิสต์ชั่วคราวในหน่วยความจำ ไม่ได้อยู่ใน save และแท็บสามปุ่มกินพื้นที่ขอบล่างโดยปุ่ม "บันทึก" เปิดดูได้เฉพาะตอนเปลี่ยนแท็บเท่านั้น

## กลไก

**ฟีดรายปีอ่านจาก timeline (Q2/Q6/Q7/Q9/Q12)**: `YearFeedView` รับ `state.timeline` ทั้งหมด แล้วกรองเฉพาะ `entry.year === state.year` ในตัวเอง ไม่มี state สำรอง ผลของปีจึงอยู่ใน save และรอด refresh ฟีดขึ้นเหนือรายการกิจกรรม หัวข้อ "บันทึกปี X" เรียงเก่าบนสุดใหม่ล่างสุดติดกับการ์ด บรรทัดซ้ำในปีเดียวกันรวมเป็นบรรทัดเดียวด้วย `groupTimelineEntries` ที่ยืมมาจาก TimelineView แสดงเฉพาะ 4 บรรทัดล่าสุด แล้วกด "ดูทั้งปี (n)" เพื่อกาง ปีที่ยังไม่มีเรื่องราวฟีดถูกซ่อนทั้งแผง ไม่โชว์หัวข้อว่าง

**ตัดวงจร news ออกจาก core (Q10)**: ลบ `GameState.newsLines`, `clearNews()`, `drainNews()`, การเขียนสองทางใน `record()` และ field `news` ใน `YearResult` เหตุผลเดิมของ news คือคัดเฉพาะบรรทัดของระบบปีนั้น ตอนนี้ timeline เป็นแหล่งเดียวที่ฟีดอ่าน ทุกบรรทัดไม่ว่าระบบหรือผู้เล่นกดก็อยู่ในปีเดียวกันอยู่แล้ว `newsLines` ไม่เคยถูก serialize การตัดจึงไม่แตะ `SAVE_VERSION` ที่ยังเป็น 1

**แถบสถานะสองสถานะ (Q3/Q4/Q5)**: `HudView` เหลือปุ่มเดียวคือแถวบน `hud-bar` ที่มีชิปสี่ตัวคือ อายุ เงิน (มี BTC 4 ตำแหน่งเสมอเพื่อ Playtest) เวลา พลังงาน กดครั้งเดียวกาง `hud-detail` คือ ชื่อ, ปี คริสตศักราช, ป้ายชั้นเรียน, มิเตอร์เวลา/พลัง, กราฟค่าสถานะสี่เส้น ตัดคำสั่ง `toggle-stats` เหลือ `toggle-hud` คำสั่งเดียว สถานะย่อ/กางเป็น state ชั่วคราวใน App เริ่มย่อเสมอ ไม่เข้า save

**สองแท็บ + หน้าย่อย lifelog (Q1/Q8/Q11/Q13)**: ตัดแท็บ "บันทึก" ออก เหลือ "กิจกรรม" กับ "อื่นๆ" ประวัติทั้งชีวิตกลายเป็นหน้าย่อย `lifelog` ที่เปิดจากรายการ "บันทึกชีวิต" ซึ่งวางถาวรหลัง "วิธีการเล่น" พร้อมปุ่มกลับ แถบสถานะแสดงเฉพาะ `tab === "act"` และตัวละครยังมีชีวิต ตายแล้วอ่านเต็มจอ

**Considered Options:** ทางเลือกหนึ่งคือคงแท็บบันทึกไว้แล้วแค่ย้ายฟีดขึ้นบน แต่แท็บที่เปิดดูได้เฉพาะตอนเปลี่ยนหน้าขัดกับเป้า "เห็นผลทันที" อีกทางคือให้ App แยกกรอง `state.history` ของปีปัจจุบันเอง แต่การแบ่งหน้าที่กรองเป็นของ view ทำให้ App เหลือแค่ส่ง timeline เปล่าๆ ให้ ส่วนทางเลือกของแถบสถานะคือปล่อยให้มีปุ่มแยกสำหรับกราฟสถิติเหมือนเดิม แต่ถูกตัดเพราะกดที่แถบเดียวจบ ลดปุ่มบนพื้นที่จอมือถือ
**Consequences:** `YearReportView` ถูกลบและแทนที่ด้วย `YearFeedView` `App` ไม่มี `lastNews` อีกต่อไป คำสั่ง `toggle-stats` เปลี่ยนเป็น `toggle-hud` และเพิ่ม `toggle-feed` ซึ่งรีเซ็ตเป็นย่อทุกครั้งที่ปีเปลี่ยน ชื่อตัวละครและป้ายชั้นเรียนอยู่เฉพาะตอนกางแถบ จึงมี test ที่ต้องกด `toggle-hud` ก่อน assert ชื่อ และ test ของป้ายชั้นเรียนก็เช่นกัน Playtest ยังอ่าน `.hud` หา BTC 4 ตำแหน่งได้เพราะชิปเงินอยู่ในแถบย่อ
