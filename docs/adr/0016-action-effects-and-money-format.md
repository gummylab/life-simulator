# การ์ดกิจกรรมบอกผลกระทบก่อนกด จัดเมนูเป็นหมู่ และปุ่มจบปีที่พูดความจริง

เกมนี้เป็นเกมตัดสินใจ แต่การ์ดกิจกรรมเดิมบอกแค่ *ต้นทุน* (เวลา พลังงาน เงิน) ไม่บอก *ผลลัพธ์* เลย ตัวเลข `effects.stats` ของทุกกิจกรรมอยู่ใน `src/content/actions.ts` แต่ไม่มีจุดไหนใน UI แสดงมัน ผู้เล่นจึงต้องจำเองว่า "อ่านหนังสือให้ +3 ปัญญา" หรือ "ไปเที่ยวให้ +10 ความสุข" ถ้าจำไม่ได้ก็กดแบบเดาสุ่ม — ซึ่งทำลายลูป "เลือกทำ → เห็นผล" ที่ ADR 0012 ตั้งใจไว้

พร้อมกันนั้น เม뉴แบบตารางสองคอลัมน์มีปัญหาสองข้อ: label ไทยยาว ๆ อย่าง "วางแผนเรียนต่อมหาวิทยาลัย" ตกบรรทัดจนอ่านยาก และตอนวัยทำงานมี 16 การ์ดปนกันโดยไม่มีโครงให้กวาดตา

และปุ่มจบปีเดิมพูดสองอย่างที่ขัดกัน: ชื่อปุ่มบอก "อายุ +1 ปี" แต่คำใบ้บอก "ยังใช้เวลาไม่หมด (N)" ผู้เล่นไม่รู้ว่ากดแล้วเกิดอะไร และไม่รู้ว่าทำไมปุ่มยังกดได้ทั้งที่เวลายังเหลือ

## กลไก

**ตัวอย่างผลกระทบ (effect preview)**: `src/ui/effectChips.ts` แปลงข้อมูลล้วนเป็นการ์ดสองแถว
- `statDeltaChips(action)` วน `STAT_KEYS` แล้วสร้างชิป "+3 ความสุข" / "−1 ปัญญา" ต่อค่าที่ไม่ใช่ศูนย์ พร้อม `data-stat` ให้ CSS ใส่สีประจำค่าได้
- `costChips(action, rateUsd)` สร้างชิปเวลา/พลังงาน/เงิน โดยเงินใช้ `moneyChip` ร่วมกันทุกที่
- `CareerView` ใช้ `moneyChip` ตัวเดียวกันกับเงินเดือน เพื่อไม่ให้มีรูปแบบเงินสองแบบ

**การจัดหมู่เมนู**: การจัดหมู่เป็นเรื่องของ UI ไม่ใช่กติกา จึงเก็บไว้ที่ `src/ui/actionGroups.ts` (แบบเดียวกับที่ `ACTION_ICONS` เก็บไอคอนไว้ชั้น ui) มีสี่หมู่คือ ดูแลตัวเอง / เรียนรู้และเล่น / งานและรายได้ / ความสัมพันธ์ พร้อม `ACTION_GROUP_OF` ที่ map ทุก id และ test คุมความครบ (เหมือน `Icons.test.ts`)

`MenuView` เรนเดอร์เป็นการ์ดแถวเดียวต่อแถว จัดหมู่ด้วย `.group-title` และเรียงหมู่ที่ "มีของกดได้" ขึ้นก่อนเสมอ เพื่อให้การ์ดที่กดได้อยู่ใกล้มือที่สุดเสมอ ส่วนการ์ดที่ถูกบล็อกเพื่อเหตุผลอื่นยังซ่อนใต้ disclosure "ยังทำไม่ได้ (n)" ตามมติ Round 18 และการ์ดที่ติดอายุยังโชว์ต่อเพราะเป็นสัญญา `showFrom`

**การ์ดที่ถูกบล็อกยังอ่านได้**: เดิมใช้ `opacity: 0.5` ทั้งการ์ด ทำให้ข้อความเหตุผลที่เป็นประโยชน์ที่สุดอ่านยากที่สุด ตอนนี้ใช้กรอบเส้นประและเปลี่ยนสี label เป็นเทา โดย `action-reason` ยังเป็นสีเตือน — เหตุผลจึงเด่นที่สุดบนการ์ดใบนั้น

**รูปแบบเงินเดียวทั้งเกม (ADR 0015 ไม่ใช่ แต่กำหนดที่นี่)**: `src/ui/money.ts` แทน `format.ts`
- USD เป็นตัวหลักทุกที่ BTC ตามหลังในวงเล็บหรือในตัวเลขรอง ยกเลิกการที่ HUD ขึ้น USD ก่อนแต่การ์ดขึ้น BTC ก่อน
- `formatUsd` ใช้ทศนิยม 2 ตำแหน่งเมื่อต่ำกว่า $100 (แก้บั๊กเดิมที่ปัดค่าต่ำกว่า $0.5 จนเหลือ `$0`) และ 0 ตำแหน่งเมื่อสูงกว่านั้น
- `formatBtc(amount, 4)` สำหรับหน้าจอ และ 8 ตำแหน่งเฉพาะชีวประวัติ/ไฟล์ (Playtest อ่าน `/\d+\.\d{4} BTC/` จาก HUD จึงคง 4 ตำแหน่งไว้)

**ปุ่มจบปีที่พูดความจริง**: `dock` สร้างปุ่มเดียวโดย
- ชื่อปุ่มบอกการกระทำ: "จบปีก่อนกำหนด" เมื่อยังมีเวลา / "จบปีนี้" เมื่อเวลาหมด และเพิ่ม `advance-early` ให้ปุ่มที่จบก่อนกำหนดเป็นปุ่มรอง (กรอบ) เพราะการเลือกกิจกรรมควรเป็นทางหลัก
- คำใบ้บอกผลลัพธ์: "เหลือเวลาอีก N · อายุ X → X+1" จึงไม่มีข้อความขัดกันอีก

**เลขาความสม่ำเสมอ**: `HudView` และชีวประวัติใช้ `formatUsd`/`formatBtc` ชุดเดียวกันทั้งหมด ไม่มีที่ไหนต่อสตริงเงินเอง

## Considered Options

- **การ์ดแถวเดียว + จัดหมู่ (เลือก)** เทียบกับคงตาราง 2 คอลัมน์แล้วแค่เพิ่มชิปผลกระทบ: ตารางสองคอลัมน์ประหยัดความสูงได้จริง แต่ชิปที่เพิ่มจะทำให้ label ตกบรรทัดหนักกว่าเดิมบนจอ 375px และการกวาดตาหาการ์ดที่กดได้จะยากขึ้น
- **บอกผลกระทบทุกค่า (เลือก)** เทียบกับบอกเฉพาะค่าบวก: การซ่อนค่าลบทำให้ผู้เล่นไม่เห็นราคาที่แท้จริงของสิ่งที่กำลังจะทำ
- **ไม่แตะรูปแบบเงิน**: ถูกตัดเพราะปัดเศษทิ้งจนเห็น `$0` เป็นบั๊กจริง ไม่ใช่แค่รสนิยม
- **เปลี่ยนชื่อปุ่มเป็น "จบปี → อายุ N+1"**: ถูกตัดเพราะชื่อปุ่มควรเป็นการกระทำที่ผู้เล่นกำลังทำ ส่วนผลลัพธ์เป็นงานของคำใบ้

## Consequences

- `tests/Icons.test.ts` ยังคุมไอคอน และเพิ่ม `tests/ActionGroups.test.ts` คุมว่าทุก action มีหมู่และทุกหมู่ที่อ้างถึงถูกประกาศจริง
- `tests/Money.test.ts` คุมการปัดเศษของ USD และจำนวนตำแหน่งของ BTC
- `Playtest.test.ts` ต้องแก้ assertion จาก `≈ $` เป็น `$` เพราะ USD เป็นตัวหลักแล้ว ไม่ใช่ตัวเลขเทียบ
- เมนูยาวขึ้นต่อการ์ดหนึ่งแถว (ชิปสองชุด) แต่สั้นลงทั้งแผงเพราะการ์ดที่กดไม่ได้ถูกซ่อนเป็นก้อนเดียว และการ์ดกว้างเต็มจออ่านง่ายขึ้น
- การเพิ่มกิจกรรมใน `actions.ts` ต้องเพิ่ม id ใน `ACTION_GROUP_OF` ด้วย ไม่งั้น test จะฟ้อง (เจตนา: ให้ล้มตอน test ไม่ใช่ให้การ์ดไปกองผิดหมู่เงียบ ๆ)
