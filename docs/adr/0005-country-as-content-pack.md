# ประเทศเป็นชุดเนื้อหาที่สลับได้ เริ่ม 2 ประเทศ

**Status:** superseded by ADR 0006 เพราะมติเปลี่ยนเป็นโลกสมมติเดียว ระบบเลือกประเทศและ `CountryPack` ถูกถอดออกจากโค้ดแล้ว โครงนี้กลับมาใช้ได้ถ้าอนาคตมีหลายโลก

เจ้าของเกมอยากให้ผู้เล่นเลือกประเทศที่จะเกิดตั้งแต่ก่อนเริ่มเกม เราจึงวาง "ประเทศ" เป็นชุดเนื้อหาชุดหนึ่งที่มีชื่อคนแบ่งตามเพศ สกุลเงิน ชื่อสถาบันการศึกษาสมมติ และชื่อสถานที่สมมติเป็นของตัวเอง โดยเริ่มที่ไทยและสหรัฐอเมริกา และเหตุการณ์สุ่มใช้ชุดเดียวกันทุกประเทศ แค่ข้อความดึงชื่อสถาบันและสกุลเงินจากประเทศของตระกูลผ่าน token

**Considered Options:** เขียนคลังเหตุการณ์แยกเป็นชุดต่อประเทศ ถูกตัดออกเพราะเนื้อหาจะเพิ่มเป็นเท่าตัวในทุกครั้งที่เพิ่มประเทศ และอีกทางเลือกคือให้เลือกประเทศเป็นแค่ป้ายกำกับโดยไม่เปลี่ยนชื่อสถาบันและสกุลเงิน ถูกตัดออกเพราะผู้เล่นจะรู้สึกว่าระบบเลือกประเทศไม่มีความหมาย

**Consequences:** เพิ่มประเทศที่ 3 คือเพิ่มไฟล์ข้อมูลใหม่แล้วลงทะเบียนใน `COUNTRY_PACKS` ไม่ต้องแตะ logic เกม แต่ทุก token ที่ใช้ในเหตุการณ์ต้องมีค่ารองรับครบทุกประเทศ ไม่เช่นนั้นข้อความจะหลุดเป็น `{school}`
