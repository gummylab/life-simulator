# ภาษาภาพแบบบันทึกชีวิต (memoir) แทนธีมเกมมืด และเลิกใช้แถบ status bar ปลอม

UI เดิมเป็น "ธีมเกมมืด" พื้นน้ำเงินเกือบดำ accent เขียวมิ้นต์ ฟอนต์ Kanit น้ำหนัก 300 ทั้งเกม และบนจอคอมล้อมด้วยกรอบโทรศัพท์ที่มีแถบ status bar ปลอม (นาฬิกา + wifi + แบตเตอรี่) ปัญหาที่เจอตอนสำรวจรอบ Phase 7 มีสามข้อ

1. Kanit เป็น display font ที่น้ำหนัก 300 อ่านยาว ๆ ลำบาก และเกมนี้เป็นเกมข้อความที่มีคนละหลายสิบปี
2. ทุกอย่างเป็น `.panel` หน้าตาเหมือนกันหมด จึงไม่มีลำดับชั้นระหว่าง "เพิ่งเกิดอะไร" "ต้องตัดสินใจอะไร" และ "ข้อมูลประกอบ"
3. แถบ status bar ปลอมกินพื้นที่ด้านบนและแสดงนาฬิกาที่โกหก (เวลาจริงของเครื่อง) โดยไม่เพิ่มข้อมูลเกมเลย

## กลไก

**โทเคนสีใหม่** (`src/styles.css`): พื้นหลังเป็นถ่านอุ่น (`--bg: #121010`) แทนน้ำเงินดำ, `--surface` / `--surface-2` แทน `--panel` / `--panel-2`, accent มิ้นต์เดิม (`#7fe3a6`) เก็บไว้เป็นสีเดียวของ "สิ่งที่กดได้" และเพิ่ม `--accent-soft` สำหรับพื้นหลังของสิ่งที่ถูกเลือก/ไฮไลต์ พร้อมแก้ตัวแปรที่เคยอ้างถึงแต่ไม่เคยประกาศ (`--surface-2` ใน `.heir-card`)

**สีประจำค่าสถานะ**: `--stat-health` (แดงกุหลาบ) `--stat-happiness` (เหลืองอำพัน) `--stat-smarts` (ฟ้า) `--stat-looks` (ม่วง) ผูกกับ `[data-stat]` บนแถวสถิติ แถบสีจึงบอกความหมายได้เองโดยไม่ต้องอ่าน label ส่วนค่า `low` (< 30) กับ `mid` (< 60) ยังทับด้วยแดง/เหลืองเพื่อให้ค่าที่แย่ตะโกนออกมา

**ฟอนต์สองชั้น**: `--font-display` = Kanit (หัวข้อ ปุ่ม ตัวเลข ป้าย) และ `--font-body` = Noto Sans Thai (เนื้อความ) โหลดจาก Google Fonts ใน `index.html` พร้อมตัดน้ำหนัก 300 ออกทั้งคู่ เนื้อความได้ `line-height: 1.65`

**ลำดับชั้น**: `.panel` ยังเป็นกล่องพื้นฐาน แต่เพิ่ม `.group-title` (ป้ายหมู่ย่อยในแผง) และเปลี่ยนปีกกาแรกของ `.advance` ให้เป็นปุ่มหลักที่ "ชื่อปุ่มบอกการกระทำ คำใบ้บอกผลลัพธ์" แทนที่การ์ดข่าว/แผงซ้อนแผงโดยไม่มีลำดับ

**กรอบมือถือไม่มีแถบปลอม**: `.device-bar` และตัวจับเวลาถูกตัดออกจาก `App.deviceTemplate` เหลือแค่กรอบขอบมนบนจอ ≥ 760px เหตุผลคือกรอบยังทำหน้าที่เตือนว่าออกแบบมาเพื่อมือถือ แต่แถบ status bar ไม่ได้ให้ข้อมูลเกมและกินความสูงจริงของจอ

**ฟีดรายปีมีจุดนำสายตา**: `.feed-line` ใช้จุด (`.feed-dot`) นำหน้า และบรรทัดล่าสุด (`data-latest`) ได้จุดสี accent พร้อมวงแหวนเรืองแสง เพื่อให้ "ผลของการกดครั้งล่าสุด" อยู่ติดกับการ์ดกิจกรรมตามเจตนาของ ADR 0013

**ลำดับการอ่านบนหน้าจอ**: `App` เก็บ `screenKey` = `tab|view` และรีเซ็ต `scrollTop` ของ `.content` เมื่อคีย์เปลี่ยน เพราะเดิมสลับแท็บแล้วตำแหน่งเลื่อนค้างจากแท็บก่อน

## Considered Options

- **A. memoir (เลือก)**: พื้นอุ่น ตัวอักษรเป็นพระเอก เนื้อความได้ฟอนต์ที่อ่านยาวได้ และใช้สีเป็นระบบความหมาย
- **B. คงธีมมืดเดิมแล้วแค่จัดสเปเซสใหม่**: ต้นทุนต่ำสุด แต่ไม่แก้ปัญหาการอ่านยาวและไม่มีลำดับชั้น
- **C. กระดาษสว่างแบบสมุดบันทึก**: เข้าธีม "บันทึกชีวิต" ที่สุด แต่ต้องรื้อสีกว่า 800 บรรทัดและเสี่ยงกับผู้เล่นที่เล่นกลางคืน
- **D. pixel/arcade**: ไม่เข้ากับเกมข้อความที่ไม่มีรูปภาพ

ทางเลือกของแถบ status bar: **ตัดออก (เลือก)** เทียบกับคงไว้ หรือย้ายนาฬิกาจริงไปไว้ในแผง "อื่นๆ"

## Consequences

- คลาสสีเดิมอย่าง `--panel` / `--panel-2` ถูกแทนด้วย `--surface` / `--surface-2` ทุก view ที่อ้างถึงจึงต้องแก้พร้อมกัน
- ทุก view ยังใช้คลาสเดิม (`.panel`, `.chip`, `.action`, `.stat`, `.hud`) เพื่อให้ DOM test ที่มีอยู่จับ regression ได้ แต่สไตล์ภายในเปลี่ยนทั้งหมด
- Kanit น้ำหนัก 300 ถูกถอดออกจาก `index.html` หน้าเว็บที่Cache ไว้จะโหลดฟอนต์ชุดใหม่แทน
- `prefers-reduced-motion` ยังเคารพอยู่ และการเปลี่ยนสี/ความกว้างยังใช้ transition สั้น ๆ
