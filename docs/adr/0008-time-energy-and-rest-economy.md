# เวลาในปี พลังงานข้ามปี และกิจกรรมพักผ่อนสองแบบ

เดิมเกมเปิดให้ทำกิจกรรมได้ไม่จำกัดจำนวนครั้งต่อปี โดยคิดว่าตัวเลขค่าสถานะที่ถ่วงน้ำหนักกันจะป้องกันไม่ให้ค่าล้น แต่ playtest จริงพบว่าไม่มีต้นทุนอะไรมาหักเลย ผู้เล่นกด "พักผ่อนอยู่บ้าน" สิบครั้งในปีแรกก็ได้ความสุข 90 และสุขภาพ 60 ทันทีที่อายุ 0 ปี เกมจึงหมดความท้าทายตั้งแต่วัยเด็ก

ระบบใหม่แบ่งเป็นสามส่วนคือ เวลาในปีที่มีจำกัดและหมดกลางปีได้จริง พลังงานที่ค่อยๆ หมดจากการทำกิจกรรมและฟื้นด้วยการพัก และกิจกรรมพักผ่อนสองแบบเพื่อให้ผู้เล่นซื้อเวลาทำอย่างอื่นคืนมาด้วยเงิน

## เวลาในปี

แต่ละปีมีเวลาตามแถบวัยคือ 0-5 ปี = 60, 6-17 ปี = 80, 18-64 ปี = 100, 65 ปีขึ้นไป = 70 ทุกกิจกรรมกินเวลาของตัวเอง ถ้ากิจกรรมทำให้เวลาเหลือศูนย์ ปีจะจบลงทันทีและจด "ปีนี้หมดเวลา" ลงบันทึกชีวิต ปุ่ม "อายุ +1 ปี" ยังกดจบปีได้เองเสมอสำหรับคนที่อยากไปต่อเร็วกว่านั้น

การเรียนและงานที่จะมาในเฟสต่อไปใช้ `committedTime` คือเวลาที่ถูกหักอัตโนมัติต้นปีก่อน เหลือเวลาว่างให้ทำกิจกรรมเสริม

## พลังงาน

พลังงานตั้งแต่ 0 ถึง 100 พกข้ามปี ทุกต้นปีบวกเพิ่ม 20 แล้ว cap ที่ 100 กิจกรรมที่มีค่าพลังงานลบถือเป็นกิจกรรมใช้แรง ถ้าพลังงานต่ำกว่า 30 จะถูกบล็อกพร้อมข้อความ "เหนื่อยเกินไป ต้องพักก่อน" กิจกรรมพักผ่อนไม่มีค่าพลังงานลบจึงไม่เคยถูกบล็อกด้วยเหตุผลนี้ ซึ่งเป็นกติกาที่รับประกันว่าจะไม่มีทางตันถาวร

## กิจกรรมพักผ่อนสองแบบ

แบบไม่เสียเงินคือการนอนหลับพักผ่อนและพักผ่อนอยู่บ้าน คืนพลังงานช้ากว่าต่อหน่วยเวลา แบบเสียเงินคือดูหนังที่คาเฟ่ นวดคลายเส้น และออกไปเที่ยวพักผ่อน คืนพลังงานเร็วกว่าต่อหน่วยเวลาและได้ความสุขเพิ่ม เป็นการใช้เงินซื้อเวลาทำอย่างอื่นคืนมา

**Considered Options:** อีกทางเลือกคือจำกัดจำนวนครั้งคงที่ต่อปี เช่น 3 ครั้ง ถูกตัดออกเพราะค่าคงที่ไม่ปรับตามวัยและไม่ให้ความรู้สึกว่าทั้งปีมีเวลาจำกัด ส่วนการลดผลลัพธ์เมื่อทำกิจกรรมซ้ำถูกตัดออกเพราะผู้เล่นจะงงว่าทำไมตัวเลขไม่ขึ้นโดยไม่รู้สาเหตุ

**Consequences:** ค่า balance ทั้งหมดอยู่ใน `src/core/config.ts` (แถบวัย ค่า restore เกณฑ์บล็อก) และใน `actions.ts` ข้างกิจกรรมนั้นๆ (ต้นทุนเวลา/พลังงาน)  invariant ที่ต้องรักษาไว้คือกิจกรรมพักผ่อนที่ถูกที่สุดต้องกินเวลาไม่เกินแถบวัยที่น้อยที่สุดเสมอ และมี test คุมไว้ใน `TimeEnergy.test.ts` แล้ว
