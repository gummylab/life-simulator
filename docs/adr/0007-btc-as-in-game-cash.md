# BTC เป็นเงินสดเดียวของเกม ราคาปีเริ่มต้นมาจากตลาดจริง

เจ้าของเกมเลือกให้ BTC ทำหน้าที่เป็นเงินสดของโลกสมมติแทนสกุลเงินทั่วไป กล่าวคือเงินเดือน ค่าเทอม รายจ่าย และมรดก ล้วนคิดเป็น BTC ทั้งหมด และมูลค่าเทียบเป็นเงินดอลลาร์ดึงจาก CoinGecko API ตอนเปิดเกมโดยไม่ต้องมี key แล้วรีเฟรชทุก 5 นาที ถ้าดึงไม่ได้ระบบใช้ราคาที่เคยเก็บไว้ใน localStorage หรือราคาประมาณการ ไม่มีทางบล็อกการเล่นเพราะเน็ตตาย

ราคา ณ วันเริ่มตระกูลคือราคาตลาดจริงของวันนั้น ส่วนปีถัดๆ ไปในเกมซึ่งยังไม่มีราคาจริงในโลกความจริง ใช้การสุ่มผันผวนต่อยอดจากฐานเดิมด้วย seed ของตระกูล เพื่อให้โหลด save ซ้ำได้เส้นราคาเดิม

**Considered Options:** ให้ผู้เล่นซื้อขาย BTC เก็งกำไรแยกจากเงินสด ถูกตัดออกเพราะเจ้าของเกมระบุว่า BTC คือเงินสดของประเทศนี้ ไม่ใช่สินทรัพย์ลงทุน และอีกทางเลือกคือใช้ราคาตลาดปัจจุบันตลอดเวลาโดยไม่สนปีในเกม ถูกตัดออกเพราะเกมเดินเข้าไปในอนาคตแล้ว

**Consequences:** ตัวเลขเงินในเกมมีเศษทศนิยมเยอะ ทุกจุดแสดงผลต้องปัดเป็น 8 ตำแหน่งและแสดงมูลค่า USD คู่กันเสมอ สูตรการสุ่มราคาปีในอนาคตห้ามถูกแตะโดยไม่เปลี่ยน schema version ของ save เพราะผู้เล่นที่โหลด save เดิมต้องเห็นเส้นราคาเดิม
