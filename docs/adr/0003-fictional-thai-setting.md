# ฉากหลังไทยแต่ชื่อสถาบันและสถานที่เป็นชื่อสมมติทั้งหมด

**Status:** superseded by ADR 0006 เพราะเกมเปลี่ยนจากฉากหลังไทยเป็นโลกสมมติของเราเองที่ไม่อิงประเทศจริง

เกมใช้ฉากหลังเป็นประเทศไทย ตัวละครมีสัญชาติและชื่อแบบไทย โครงการศึกษาเป็นแบบไทยคือประถม มัธยม และมหาวิทยาลัย แต่ชื่อโรงเรียน มหาวิทยาลัย จังหวัด และย่านที่กล่าวถึงในเกมเป็นชื่อที่เราแต่งขึ้นเองทั้งหมด

**Considered Options:** ใช้ชื่อสถาบันและสถานที่จริงเพื่อเพิ่มความอิน ถูกตัดออกเพราะไม่อยากพาดพิงถึงชื่อของคนอื่นหรือสถาบันจริง ทั้งในแง่รสชาติของเนื้อหาที่อาจพาดพิงในทางไม่ดีโดยไม่ตั้งใจ และในแง่ความยุ่งยากที่จะตามแก้ทีหลังถ้ามีคนไม่พอใจ

**Consequences:** ทุกชื่อใน `content` ต้องเป็นชื่อสมมติ การเพิ่มเนื้อหาใหม่จึงไม่ต้องตรวจสอบว่าไปอิงของจริงหรือไม่
