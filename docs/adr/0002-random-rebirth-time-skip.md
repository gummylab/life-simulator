# สืบทอดแบบสุ่มเกิดใหม่พร้อมข้ามเวลา 60 ถึง 100 ปี

ตอนตัวละครตาย เราไม่ให้ผู้เล่นเลือกว่าจะสืบทอดเป็นลูกคนไหน เพราะการเลือกทำให้เกมสะดุดและผู้เล่นมองว่าไม่สนุก แทนที่ด้วยการกระโดดเวลาไปข้างหน้า 60 ถึง 100 ปี แล้วสุ่มเกิดใหม่เป็นลูกหลานในตระกูลเดิม พร้อมสร้างบันทึกตระกูลของรุ่นที่ข้ามผ่านให้อ่านก่อนเกิด

**Considered Options:** ให้ผู้เล่นเลือกทายาทเองแบบเกมแนวตระกูลทั่วไป ถูกตัดออกตามที่เจ้าของเกมประเมินไว้ว่าการเลือกไม่ได้เพิ่มความสนุก และอีกทางเลือกหนึ่งคือจบเกมทันทีเมื่อตัวละครแรกตาย ถูกตัดออกเพราะเป้าหมายของเกมคือเล่นได้เรื่อยๆ แบบตระกูล

**Consequences:** ต้องมีระบบสร้างลำดับลูกหลานแบบสุ่มและหักมรดกลงตามช่วงเวลาที่ข้าม เพื่อไม่ให้ตระกูลที่ร่ำรวยอยู่แล้วครองเกมไปทุกรุ่น
